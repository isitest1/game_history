# 生まれ年ガチャ（仮称）

同じ一人の人間が、30年ずつ離れた3つの時代に同時に生まれます。

性格も、才能も、生まれた県も、家の暮らし向きも同じです。違うのは生まれた年だけです。あなたが決断すると、その選択は3人全員に当てはまります。ただ、結果を決めるのはそれぞれの時代です。

- 1935年の彼は大学に行きたかったものの、15歳で集団就職した
- 1965年の彼は共通一次を受け、バブル期に大企業に入った
- 1995年の彼は奨学金を400万円借り、就職氷河期の最後の年に卒業した

進学・就職・結婚・寿命・年金は、すべて日本の実際の統計で判定します。

## 状態

最初から最後まで、通しで遊べる試作版があります（2026年10月15日）。

```bash
npm install
npm run dev        # http://localhost:5173/ で遊べる
npm test           # シミュレーションのテスト（実験室を含む）
npm run build      # dist/ に静的サイトを書き出す
```

- 技術：Vite + TypeScript（フレームワークなし）、Vitest、Playwright
- 統計：`data/stats/`（加工スクリプトは `scripts/build_*.py`）
- 出来事：`data/events/`（862件）
- 夜間作業の報告：[docs/夜間作業レポート.md](docs/夜間作業レポート.md)
