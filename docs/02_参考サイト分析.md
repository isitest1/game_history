## 1. 全体の仕組み

| 項目 | 内容 |
|---|---|
| 動く場所 | シミュレーションはすべてブラウザの中。約2.8MBのJavaScript 1本で、難読化されていない。関数は約1,200個 |
| 言語 | 韓国語で書かれ、日本語と英語は翻訳辞書で置き換えている |
| 保存 | 途中の状態はすべてlocalStorage。閉じても続きから再開できる |
| 1年の進め方 | 年の初めに、その年の出来事2〜3件と決断最大2件を、年内のランダムな時刻に予約する。時刻が来たら発動する |
| 出来事の数 | 約460種類 |
| 国のデータ | 172か国 × 約35指標（出生数、人口、平均寿命、男女の寿命差、乳児死亡率、5歳未満の死亡率、1人あたりGDP、ジニ係数、出生率、都市に住む人の割合、喫煙率、医療費の自己負担割合、児童婚の割合、戦争、移民の主な行き先、災害の種類など） |
| 死亡 | 実際の生命表は使っていない。平均寿命・乳児死亡率・5歳未満の死亡率から、年齢ごとの死亡率を計算で作る（ゴンペルツ・メイカム型の式）。そこに、健康の数値、家の豊かさ、喫煙、飲酒、治療していない病気、難民かどうかなどの倍率をかけて、毎年抽選する |
| 死因 | 国・年齢・性別ごとの重みで選ぶ |
| 過去と未来 | 別ファイル（約550KB）。国連の世界人口推計2024などから、各国の1950〜2100年の推移を持ち、現在の指標を補正する。最も古い生まれ年は1950年 |
| 国ごとの歴史的な出来事 | 127件。「国・年・対象の年齢・確率・文章・効果」の形。韓国は14件、日本は3件だけ（1950年の朝鮮特需、1964年の東京五輪、1995年の阪神・淡路大震災） |
| サーバー | いま遊んでいる人数の集計、「みんなの人生」への投稿、メモリアル、「前世の家」、有料パス |
| 収益 | 遊ぶのは無料。「思い出パス」$3（Stripe）で、人生の短い映像・アルバム・メモリアル・全記録の保存などが使えるようになる |

## 3. 参考サイトの弱いところ

- 日本についての情報が薄い（歴史的な出来事は3件）
- 1950年より前の生まれがない
- 死亡率は要約値からの推計で、実際の生命表ではない
- 統計の引用に別の国のデータが混ざる（フィリピン人の婚約の話に米国の調査を使うなど）
- 1回の人生に約1時間かかる
