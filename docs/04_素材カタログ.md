# 04 素材カタログ

物語の素材（出来事）の設計図。素材は `data/events/*.json` に置き、シミュレーションが毎年、条件に合うものを確率で引く。

- 作成：2026年10月14日（夜間作業）
- 全体の目標：500〜1000件。初回（今夜）の目標は300件以上

---

## 1. 1件のデータ形式

1ファイルは、次の形のオブジェクトの配列にする。

```jsonc
{
  "id": "war-1945-03-tokyo-airraid-child",   // 一意。カテゴリ-年-月-内容-年齢帯
  "key": "tokyo-airraid-1945",               // 同じ出来事を年齢別に書き分けたものは同じ key にする
  "category": "war",                          // 下の「2. カテゴリ」の id
  "year": 1945,                               // 起きた年（西暦）
  "endYear": 1945,                            // 何年も続くもの（疎開、闇市など）は最後の年。単年なら省略
  "month": 3,                                 // 分かれば。分からなければ省略
  "prefs": [13],                              // 都道府県コード（JIS X 0401、1〜47）。全国なら省略
  "ageMin": 6, "ageMax": 12,                  // その年の満年齢の範囲（両端を含む）
  "sex": "any",                               // "any" | "male" | "female"
  "conditions": {                             // 省略可。すべて満たすときだけ発生
    "education": ["univ"],                    // "none" | "middle" | "high" | "junior" | "univ"（最終学歴または在学中）
    "job": ["farm", "self", "smallco", "bigco", "public", "none"],
    "married": true,
    "familyClass": [1, 2],                    // 家の暮らし向き 1（苦しい）〜5（豊か）
    "flags": ["evacuated"],                   // 先に立ったフラグ
    "notFlags": ["dead_parent"]
  },
  "title": "東京大空襲",                        // 人生の記録に出る短い見出し（20字以内）
  "text": "3月10日の未明、住んでいた下町が焼けた。家族と逃げ、翌朝、焼け跡に戻った。",
                                              // 本人の体験として書く（60〜120字）。その年齢で見えたこと・感じたことにする
  "effects": {                                // 状態の変化（-30〜+30）。省略可
    "health": -5, "happiness": -15, "knowledge": 0, "relation": 0,
    "money": 0,                               // 純資産の変化（当時の円）。多くの出来事では 0
    "flags": ["airraid_survivor"],            // 立てるフラグ
    "death": { "prob": 0.01, "cause": "空襲" }  // この出来事で亡くなる確率（追加分）。ほとんどの出来事では書かない
  },
  "probability": 0.6,                         // 条件に合う人が、その年にこの出来事に出会う確率（0〜1）
  "heavy": true,                              // 戦争・災害・病気・自殺など重い出来事なら true（相談先を案内する）
  "source": {
    "title": "総務省 国内各都市の戦災の状況（東京都）",
    "url": "https://www.soumu.go.jp/...",
    "verified": true                          // 年・数字をWebで確かめたら true。確かめられなければ false（＝未確認）
  }
}
```

### 書き方の決まり

- **同じ出来事でも、経験した年齢で書き分ける。** 少なくとも「子ども（0〜12歳）」「若者（13〜29歳）」「大人（30〜59歳）」「高齢者（60歳〜）」のうち、その出来事に関係する年齢帯ごとに1件ずつ作り、`key` をそろえる
- 文章は本人の目線で、過去形、です・ます調にしない（「〜した」「〜だった」）。説明文にしない
- **重い出来事は場面を描写しない。** 事実（何が起きたか、どこで、何人）と、本人の立場（家族を失った、家が焼けた）だけを書く。`heavy: true` を付ける
- 実在の個人名は、公人（首相など）と作品名・曲名だけにする。**歌詞は使わない**
- `probability` は、統計があればそれから決める（例：疎開の対象人数÷対象年齢の人口）。なければ目安で置き、`source.verified` とは別に、`"probNote": "目安"` を付ける
- 数字・年は WebSearch で確かめる。確かめられなければ `verified: false`

## 4. 決断（素材とは別）

決断は「本人が望んだこと」を選び、結果は時代と家の事情が決める。決断の形式は `src/sim/decisions.ts` の型に従う。

- 選択肢ごとに、「選べるか（条件と理由）」と、「望んでも叶わない確率」を時代の統計から計算する
- 3人を並べたとき、同じ選択から違う結果が出る場面を20個以上作る

### 戦死の確率の決め方

**1. 生まれ年ごとの男子の戦没率（目標）**

生まれ年ごとの戦没率そのものを示す公的な統計は見つからなかった。そこで、次の3つから目標を置いた。

- **総数**：先の大戦の戦没者約310万人のうち、軍人・軍属は約230万人（厚生労働省）
- **一番多く亡くなった世代**：1947年の国勢調査では、男女の比が21歳から下がり始め、26歳（1920〜21年生まれ）で0.76まで下がる。1950年には29歳で約0.78。年齢別の比の落ち込みは40歳ごろまで見られる（Ogasawara & Igarashi, 2024。国勢調査から作成）。戦前の同じ年齢の比を約1.0とすると、1920〜21年生まれの男子の約2割強が戦争で減ったことになる
- **時期**：日本人の戦没者の約9割は1944年以降に亡くなったと推算されている（吉田裕『日本軍兵士』。文春オンラインの書評で確認）
- 「大正生まれの男性の7人に1人が戦死した」という言い方もある（書籍の紹介文。出典の計算は未確認）。下の表の1912〜26年生まれの平均は約16%で、おおむね合う

**3. 確率の組み立て**

戦没率 ＝ 兵士になる確率 × 兵士が戦地で亡くなる確率、に分けた。

- **兵士になる（key `mobilized`、1回だけ）**：時期（1937〜41／42〜43／44〜45）× 年齢帯（現役 20〜21歳〈1944年から19〜21歳〉／召集 22〜32歳／33〜40歳〈1943年から45歳〉）ごとに、1年あたりの確率の合計を決めた。1937〜41年：0.33／0.08／0.025、1942〜43年：0.42／0.18／0.04、1944〜45年：0.50／0.30／0.06。これを戦地の比（1937〜41年 中国0.78・満州0.22、1942〜43年 中国0.3・満州0.2・南方0.5、1944〜45年 中国0.12・満州0.1・南方0.33・本土0.45）で、同じ key の出来事に割り振った（どれか1つが当たる。各出来事の確率 p_i = k×比 とし、1−Π(1−p_i) が合計になる k を求めた）
- **戦地での1年（死亡はここ）**：戦地ごと・年ごとの出来事（確率0.9。1939〜41年の中国などは数年に1回）に、その年に亡くなる確率を置いた。中国 1937年0.03・1938年0.03・1939〜41年0.03・1942〜43年0.025・1944年0.05・1945年0.05、満州 1937〜43年0.015・1945年（ソ連軍の侵攻）0.12、南方 1942年0.04・1943年0.06・1944年0.25・1945年0.30、輸送船の沈没（1943〜45年、1年あたり0.3で起き、起きた人の0.25が死亡）、本土 1945年0.05。1944〜45年に入営・召集された人は、その年のうちに亡くなることも多かったため、入営・召集の出来事そのものに 0.01〜0.05 を置いた
- エンジンはその年のはじめのフラグで候補を選ぶため、兵士になった年の翌年から「戦地での1年」が出る。1945年に入営した人がほとんど亡くならないのはこのため（実際も1945年の入営者の多くは本土にいた）
- 負傷して除隊（1年あたり0.03）、満州から南方への転用（1943〜44年、1年あたり0.2）も入れた
- **シベリア抑留**：終戦時に満州の部隊にいて南方へ移っていない兵のうち0.8が抑留される（終戦時の兵力が未確認のため目安）。収容所の冬（確率0.95）の死亡の確率0.101 は、亡くなった人約5万5千人÷抑留者約57万5千人＝約9.6% を0.95で割ったもの。帰国は1946年0.1、1947〜50年は1年あたり0.6、1953〜56年は0.7
- **家族**：夫の出征（1937〜41年0.04、42〜45年0.09／年）、兄弟の出征（0.1、0.2）、息子の出征（0.05、0.15）。結末は「戦死の公報（1938〜43年0.015、1944〜47年0.08／年）」と「復員（1945〜48年0.5／年）」を同じ key にして、どちらか1つだけが起きるようにした。出征した家族が亡くなる割合は約20〜22%（上の男子のシミュレーションの「兵士のうち亡くなる割合」約20〜26%に合わせた）。結果として、1900〜15年生まれの女性の約8%が夫を、約16%が兄弟を戦争で亡くす。遺族になる人は1900年生まれの女性で約29%

### 二重に数えていないかの確認

- **生命表**：`data/stats/README_mortality.md` によると、1930〜43年は第5回・第6回（1935〜36年）・第8回（1947年）の生命表の補間、1944〜46年は1943年と1947年の補間で、「戦争による死亡はゲーム側の出来事として別に扱うため含めない」。補間のもとの表はどれも戦闘のない年のものなので、**生命表から差し引くものはない**。戦死は `war_adult.json` の出来事だけで数える
- ただし、戦地の兵士にも生命表のふつうの死亡（20代男子で1年に約1%弱）がかかる。戦没者には戦病死が多く含まれるため、兵士だった数年間はこの分がわずかに重なる（戦没率に比べて小さいので、今は差し引いていない。差し引くなら、`soldier` を持ち `demobilized` を持たない1937〜45年の男子の生命表の死亡率を下げる処理をエンジンに足す）
- **民間人の死亡**：`war.json` の空襲・原爆・沖縄戦は15歳までしか扱っていなかった。大人の分は、主な都市（東京・大阪・名古屋・神戸・横浜）・広島・長崎・沖縄戦について、`war.json` と同じ key・同じ確率・同じ死亡率で、16歳以上の版を作った。同じ key なので年齢が重ならず、一生に1回しか起きない。出征中の兵士（`soldier`）には出さない。ほかの都市の空襲の大人版、満州の民間人（開拓団）の大人版はまだない
