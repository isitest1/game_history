# 04 素材カタログ

物語の素材（出来事）の設計図。素材は `data/events/*.json` に置き、シミュレーションが毎年、条件に合うものを確率で引く。

- 作成：2026年10月14日（夜間作業）
- 全体の目標：500〜1000件。初回（今夜）の目標は300件以上

---

## 1. 1件のデータ形式

1ファイルは、次の形のオブジェクトの配列にする。

```jsonc
{
  "id": "war-1945-03-tokyo-airraid-child",   // 一意。カテゴリ-年-月-内容-年齢帯
  "key": "tokyo-airraid-1945",               // 同じ出来事を年齢別に書き分けたものは同じ key にする
  "category": "war",                          // 下の「2. カテゴリ」の id
  "year": 1945,                               // 起きた年（西暦）
  "endYear": 1945,                            // 何年も続くもの（疎開、闇市など）は最後の年。単年なら省略
  "month": 3,                                 // 分かれば。分からなければ省略
  "prefs": [13],                              // 都道府県コード（JIS X 0401、1〜47）。全国なら省略
  "ageMin": 6, "ageMax": 12,                  // その年の満年齢の範囲（両端を含む）
  "sex": "any",                               // "any" | "male" | "female"
  "conditions": {                             // 省略可。すべて満たすときだけ発生
    "education": ["univ"],                    // "none" | "middle" | "high" | "junior" | "univ"（最終学歴または在学中）
    "job": ["farm", "self", "smallco", "bigco", "public", "none"],
    "married": true,
    "familyClass": [1, 2],                    // 家の暮らし向き 1（苦しい）〜5（豊か）
    "flags": ["evacuated"],                   // 先に立ったフラグ
    "notFlags": ["dead_parent"]
  },
  "title": "東京大空襲",                        // 人生の記録に出る短い見出し（20字以内）
  "text": "3月10日の未明、住んでいた下町が焼けた。家族と逃げ、翌朝、焼け跡に戻った。",
                                              // 本人の体験として書く（60〜120字）。その年齢で見えたこと・感じたことにする
  "effects": {                                // 状態の変化（-30〜+30）。省略可
    "health": -5, "happiness": -15, "knowledge": 0, "relation": 0,
    "money": 0,                               // 純資産の変化（当時の円）。多くの出来事では 0
    "flags": ["airraid_survivor"],            // 立てるフラグ
    "death": { "prob": 0.01, "cause": "空襲" }  // この出来事で亡くなる確率（追加分）。ほとんどの出来事では書かない
  },
  "probability": 0.6,                         // 条件に合う人が、その年にこの出来事に出会う確率（0〜1）
  "heavy": true,                              // 戦争・災害・病気・自殺など重い出来事なら true（相談先を案内する）
  "source": {
    "title": "総務省 国内各都市の戦災の状況（東京都）",
    "url": "https://www.soumu.go.jp/...",
    "verified": true                          // 年・数字をWebで確かめたら true。確かめられなければ false（＝未確認）
  }
}
```

### 書き方の決まり

- **同じ出来事でも、経験した年齢で書き分ける。** 少なくとも「子ども（0〜12歳）」「若者（13〜29歳）」「大人（30〜59歳）」「高齢者（60歳〜）」のうち、その出来事に関係する年齢帯ごとに1件ずつ作り、`key` をそろえる
- 文章は本人の目線で、過去形、です・ます調にしない（「〜した」「〜だった」）。説明文にしない
- **重い出来事は場面を描写しない。** 事実（何が起きたか、どこで、何人）と、本人の立場（家族を失った、家が焼けた）だけを書く。`heavy: true` を付ける
- 実在の個人名は、公人（首相など）と作品名・曲名だけにする。**歌詞は使わない**
- `probability` は、統計があればそれから決める（例：疎開の対象人数÷対象年齢の人口）。なければ目安で置き、`source.verified` とは別に、`"probNote": "目安"` を付ける
- 数字・年は WebSearch で確かめる。確かめられなければ `verified: false`

---

## 4. 決断（素材とは別）

決断は「本人が望んだこと」を選び、結果は時代と家の事情が決める。決断の形式は `src/sim/decisions.ts` の型に従う。

- 選択肢ごとに、「選べるか（条件と理由）」と、「望んでも叶わない確率」を時代の統計から計算する
- 3人を並べたとき、同じ選択から違う結果が出る場面を20個以上作る

---

## 5. 優先順位

1. 3つの時代の差がはっきり出るもの（戦争、高度成長、オイルショック、バブル、就職氷河期、震災、コロナ）
2. 制度の変わり目
3. 都道府県ごとの出来事
4. 暮らし・流行
