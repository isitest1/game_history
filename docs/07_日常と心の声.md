# 07 日常と心の声

## なぜ作るか

参考サイト「80億分の1」を実際に3人分、最後まで遊んだ（2026-10-15。過去の世界で2人、いまの世界で1人。自動で選んで16倍速）。
分かったことは次のとおり。

| | 参考サイト | このゲーム（作る前） |
|---|---|---|
| 1年あたりの記録 | 約7件（重複を除くと3〜5件） | 約1.3件 |
| 記録が1件もない年 | 0〜1年（一生で） | 全体の44%（30組90人の一生で数えた） |
| 書かれていること | 出来事・決断のほかに、毎日の小さな場面が多い | 出来事・決断・学校・仕事・家族の節目だけ |

ユーザーの指摘：「その時の出来事や、望みが叶った・叶わなかっただけでは物語にならない。それぞれの人が何を思い、どう過ごしたかという日常が要る」。

## 参考サイトから学んだこと（考え方だけ。文章・データは使わない）

1. **同じ人が何度も出てくる**：親友、恋人と配偶者、子ども、ペット、祖父母に名前があり、何年もあとにまた出てくる。親の年齢を添える（例：その年の母の年齢）
2. **体の小さな変化**：初めての白髪、腰痛、ひどい風邪で数日寝込む
3. **「初めて」**：初めての言葉、初めての携帯電話、初めてインターネットにつながる
4. **家族の行事**：正月を家族で過ごす、祖母の手料理、結婚記念日に古い写真を見る
5. **人との機微**：ささいな誤解で疎遠になり、自分から謝ってまた親しくなる。何年も前に助けた人がお礼を言いに来る
6. **心の支え**：つらい時期に趣味が支えになる
7. **子どものころの夢**：「大きくなったら何になりたい？」にいつも同じ答えをしていた
8. **世の中の空気**：ある言葉が毎日のようにテレビや新聞に出るようになった
9. **介護**：親に一晩付き添う、病院代を送る
10. **節目の生存割合**：同じ年に生まれた人のうち何%がいまも生きているか

このゲームでは、これに **心の声**（その人がそのとき思ったこと）を足す。参考サイトには少ない部分で、ユーザーが求めている「何を思って」にあたる。

## 作るもの

### 1. 日常（kind: `daily`）

- 毎年、生きている人それぞれに **2件前後** の日常の場面を出す（乳幼児は1〜2件）
- 時代（その年の西暦）、年齢、男女、家族、学校、仕事、結婚、子ども、都会か地方か、暮らし向き、気分（幸福の高さ）で選ぶ
- 同じ場面は一生に1回まで（`repeatGap` を付けたものだけ、その年数をあけて繰り返す）

### 2. 心の声（kind: `think`）

- 「」でくくった一人称の短い言葉。画面では引用の形で出す
- その年に起きたこと（結婚、子どもの誕生、親の死、就職、退職、病気、望みが叶わなかった、引っ越し）を **きっかけ（trigger）** にして選ぶ。きっかけがない年は、年齢・時代・気分から選ぶ
- 1年に1件まで。出る確率はおよそ6割

### 3. 続いていく人たち（プログラムで作る）

- **親友**：6〜10歳でできる。同じ時代の名前。高校を出るころ疎遠になることがあり、何十年かたって再会することがある
- **配偶者**：結婚の年に名前が付く。結婚10・25・40・50周年に場面が出る
- **子ども**：生まれた年に名前が付く。小学校入学、成人、結婚、孫の誕生で場面が出る
- **ペット**：飼うことがある。時代に合った名前。十数年後に見送る
- **親の年齢**：親が出てくる場面に、その年の親の年齢を添える
- **生存割合**：10・20・30…歳の節目に、同じ年に同じ性別で生まれた人のうち何%がいまも生きているかを、このゲームの生命表（`data/stats/mortality.json`）から計算して出す
- **回想**：50歳を過ぎると、ときどき昔の記録（決断、叶わなかった望み、大きな出来事）を思い出す

## データの形（`data/daily/*.json`）

ファイルは配列。1件はこの形。

```json
{
  "id": "d12-031",
  "kind": "daily",
  "ageMin": 8,
  "ageMax": 11,
  "yearMin": 1955,
  "yearMax": 1970,
  "when": { "urban": false, "hasSibling": true },
  "text": "夕方、{sib}と川でザリガニを捕った。バケツいっぱいにして帰ったら、母に「元の川に返してきなさい」と言われた。",
  "effects": { "happiness": 1 },
  "weight": 1,
  "check": "未確認"
}
```

| 項目 | 意味 |
|---|---|
| `id` | ファイル内で重ならない名前 |
| `kind` | `daily`（日常）か `think`（心の声） |
| `ageMin` `ageMax` | その人の年齢の範囲 |
| `yearMin` `yearMax` | その年（西暦）の範囲。時代に結びつくものには必ず付ける。どの時代にもある場面には付けない |
| `when` | 条件（下の表）。書かなかった条件は問わない |
| `text` | 本文。常体の過去形（「〜した。」）。心の声は「」でくくる |
| `effects` | 小さな変化（health / happiness / knowledge / relation、それぞれ −3〜+3） |
| `weight` | 選ばれやすさ（ふつう1） |
| `repeatGap` | 繰り返してよい場合の、あける年数 |
| `check` | 時代の事実を含むものは、確かめた資料（例：「確認済み：任天堂の会社沿革」）。確かめていないものは「未確認」。事実を含まないものは書かない |

### `when` で使える条件

| 条件 | 値 | 意味 |
|---|---|---|
| `sex` | `male` / `female` | 性別 |
| `married` | true / false | いま結婚している（配偶者が生きている） |
| `widowed` | true | 配偶者を亡くしている |
| `hasChildren` | true / false | 子どもがいる |
| `childAge` | [最小, 最大] | いずれかの子の年齢がこの範囲 |
| `hasSibling` | true / false | きょうだいがいる |
| `mother` `father` | true / false | 母・父が生きている |
| `school` | `elem` / `middle` / `high` / `univ` | いま通っている学校 |
| `working` | true / false | いま働いている |
| `job` | [`farm`, `self`, `smallco`, `bigco`, `public`] | 仕事の種類 |
| `retired` | true | 退職している |
| `urban` | true / false | 大都市圏に住んでいる（生まれか、都会へ出た） |
| `rich` / `poor` | true | 暮らし向きが上（4〜5）／下（1〜2） |
| `mood` | `low` / `high` | 幸福が低い（35未満）／高い（70以上） |
| `sick` | true | 健康が低い（40未満） |
| `flags` / `notFlags` | 文字列の配列 | 付いている／付いていないフラグ（smoker、homeowner、moved_to_city など） |
| `trigger` | 下の一覧 | 心の声のきっかけ。その年にそれが起きたときだけ選ばれる |
| `region` | 地方の配列 | 住んでいる地方（生まれた県で決まる）。`hokkaido` `tohoku` `kanto` `hokuriku` `koshin` `tokai` `kinki` `chugoku` `shikoku` `kyushu` `okinawa` |
| `prefs` | 県番号の配列 | 住んでいる県（1 北海道 … 13 東京都 … 27 大阪府 … 47 沖縄県。JIS の都道府県コード） |
| `snow` | true / false | 雪の多い県（北海道・東北6県・新潟・富山・石川・福井・長野・鳥取。県全体でみた目安） |

`trigger` の値：`married`（結婚した）、`child`（子が生まれた）、`parent_death`（親を亡くした）、`spouse_death`（配偶者を亡くした）、`job`（働き始めた・転職した）、`retire`（退職した）、`ill`（病気・入院）、`wish_fail`（望みが叶わなかった）、`moved`（都会へ出た）、`school`（入学した）。

### 本文で使える差し込み

差し込みを使った場面は、その人に当てはまるときだけ選ばれる（例：`{spouse}` は配偶者が生きているときだけ）。

| 差し込み | 中身 |
|---|---|
| `{name}` | 本人の名（姓なし） |
| `{friend}` | 親友の名 |
| `{spouse}` | 配偶者の名 |
| `{child}` | 子の名（条件に合う子のひとり） |
| `{childAge}` | その子の年齢 |
| `{sib}` | きょうだいの呼び方（兄・姉・弟・妹） |
| `{pet}` | ペットの名 |
| `{pref}` | 住んでいる都道府県 |
| `{mAge}` `{fAge}` | 母・父のその年の年齢 |

## 書くときの決まり

- 参考サイトの文章は使わない。考え方だけを参考にする
- 歌詞は書かない（曲名はよい）。実在の個人を出さない（有名人の名前も出さない）
- 戦争・災害・病気・自殺などの重い場面は、日常の場面では描写しない（それらは出来事の側で扱い、相談先を案内する）
- 時代の事実（発売年、放送開始年、制度）は確かめてから書く。確かめられないものは `check` に「未確認」と書く
- 2027年より先の年は、何が起きるか分からないので、時代に結びつけない（どの時代にもある場面だけを出す）
- その時代の暮らしの実感が伝わるように書く。同じ場面でも、時代で道具や言葉が変わる（例：電話は黒電話→公衆電話・ポケベル→携帯→スマホ）

## 作った結果（2026-10-15）

| | 数 |
|---|---|
| 日常（daily） | 1,207件 |
| 心の声（think） | 357件 |
| 時代に結びつけた場面 | 497件（うち資料で確かめたもの198件、`check` が「未確認」のもの299件） |

ファイルは年齢で6つに分けた：`stage0_infant`（0〜5歳）、`stage1_child`（6〜12歳）、`stage2_teen`（13〜18歳）、`stage3_young`（19〜34歳）、`stage4_middle`（35〜64歳）、`stage5_old`（65歳以上）。
確かめた事実（発売日、放送開始日、制度の開始日など）は、各場面の `check` に資料名を書いた。

### 一生の記録の量（30組90人の一生で数えた。`tests/daily.test.ts`）

| | 作る前 | 作ったあと |
|---|---|---|
| 記録が1件もない年 | 44% | 1%未満（約7,000年のうち1〜2年） |
| 1年あたりの日常 | 0 | 約2.5件 |
| 1年あたりの心の声 | 0 | 約0.6件 |

### 画面

- スマホでは、同い年の3人それぞれについて、大事な出来事1件と、その下に心の声（なければ日々のこと）1件を出す。心の声は左に線を引いた引用の形
- 最後の画面に「それぞれが、そのとき思ったこと」を足した。子ども・若いころ・働き盛り・50〜60代・老後から1つずつ

### 話のつじつまを守るしかけ（`src/sim/daily.ts`）

条件の書き忘れがあっても、次の場面は出さない。
- 職場の言葉（上司、残業、同僚など）がある場面：働いていない人には出さない
- 授業・部活・修学旅行などの場面：15歳以上で学校に通っていない人には出さない。講義・ゼミなどは大学・短大に通う人だけ
- 奨学金の場面：奨学金を借りた人だけ
- 「新婚」「結婚して初めて」の場面：結婚して2年以内の人だけ
- 孫の場面：孫が生まれた人だけ。「ばあば」「じいじ」と呼ばれる場面は性別を合わせる
- 親友ができた年は、親友との別の場面を重ねない
- 親友・配偶者・子の名前は、3人の主人公の名前や、ほかの身近な人の名前と重ならないようにする

### 決めたこと

- 校内暴力の場面（中高生の担当が1件書いた）は、重い場面にあたるので外した
- 戦後の教科書の墨塗りの場面は、暴力の描写がなく、暮らしの変化として残した
- 親が子の名前を一瞬思い出せない場面（中年の担当が1件書いた）は、病気の描写がないので残した


## 追加（2026-10-15）：時代のリアルさと、県による違い

ユーザーの指摘「日々の暮らし、もっとリアルな当時のものを」「県による違いをもっと」を受けて、場面を足した。

| ファイル | 中身 | 件数（daily／think） |
|---|---|---|
| `era_1930s50s.json` | 1930〜59年。配給と切符、はがき・銭湯・そば・映画の当時の値段、木炭バス、街頭テレビなど | 141／35 |
| `era_1960s70s.json` | 1960〜79年。即席めんの値段、マクドナルド1号店、歩行者天国、光化学スモッグ、ボウリングなど | 160／33 |
| `era_1980s90s.json` | 1980〜99年。テレホンカード、たまごっち、テレホーダイ、タイ米、Gコードなど | 147／35 |
| `era_2000s20s.json` | 2000〜26年。写メール、パケ・ホーダイ、mixi、Suica、牛丼の値段、マイナポイント、米の高騰など | 137／36 |
| `region_north.json` | 北海道・東北 | 156／36 |
| `region_center.json` | 関東・甲信・北陸・東海 | 141／33 |
| `region_west.json` | 近畿・中国・四国・九州・沖縄 | 162／40 |

条件に `region`（地方）、`prefs`（県）、`snow`（雪の多い県）を足した。

### しくみ
- 県や地方の場面は、生まれた県に住み続けている人だけに出る。都会へ出た人には、上京した人向けと書いた場面（`flags: ["moved_to_city"]`）だけを出す
- 毎年およそ3割の確率で、県や地方の場面を先に1つ選ぶ。時代を問わない土地の暮らし（祭り・雪・名物）は、12年あければまた出る
- 40組120人の一生で数えると、日々の場面のうち県や地方の場面は約9%（足す前は約4%）、時代に結びついた場面は約18%
- 親友が引っ越した・転校した場面のあとは、親友は疎遠の扱いになる

### 決めたこと
- 戦時中の防空頭巾と金属の供出の場面、平成への改元の空気の場面は、空襲や死を描いていないので残した
- 心の声は短い一言（20〜40字）のままでよい（日常の本文だけ40〜90字）
