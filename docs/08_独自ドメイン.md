# 08 独自ドメイン（umaredoshi.margheritaworks.com）

## 決めたこと（2026-10-15）

- 公開の住所を **https://umaredoshi.margheritaworks.com/** にする。名前は「生まれ年ガチャ」の読みから
- ドメイン margheritaworks.com はユーザーが Cloudflare で持っている。サブドメインを GitHub Pages に向ける
- 設定は Claude が API で行う（ユーザーの依頼「お前が全部やる。トークンを渡す」）

## 仕組み

| 場所 | 設定 |
|---|---|
| Cloudflare の DNS | CNAME `umaredoshi` → `isitest1.github.io`、**プロキシはオフ（DNSのみ）**。オンだと GitHub が証明書を発行できない |
| GitHub Pages | Custom domain に `umaredoshi.margheritaworks.com`、証明書ができたら Enforce HTTPS |
| ゲームの中の住所 | 共有リンク（`src/ui/share.ts`）、OGP・canonical・構造化データ（`index.html`）、`public/sitemap.xml`、`public/robots.txt` を新しい住所に（PR #15） |

古い住所 `isitest1.github.io/game_history/` は、Custom domain を入れると GitHub が新しい住所へ転送する。

## トークン（チャットには貼らない。クラウド環境の設定に入れる）

| 変数名 | 作り方 | 権限 |
|---|---|---|
| `CLOUDFLARE_API_TOKEN` | Cloudflare → 右上のアイコン → マイプロフィール → API トークン → トークンを作成 → 「DNS を編集する」のテンプレート | ゾーン：DNS：編集、対象ゾーン：margheritaworks.com |
| `GITHUB_PAGES_TOKEN` | GitHub → Settings → Developer settings → Fine-grained tokens → Generate | Repository access：isitest1/game_history のみ。Permissions：Administration（Read and write）、Pages（Read and write） |

入れる場所：このセッションの上のクラウド環境の名前 → 編集 → 環境変数（またはネットワークのシークレット）。**新しいセッションから読み込まれる。**

## トークンを入れたあとに、次のセッションでやること

1. `bash scripts/setup_domain.sh` を実行する（DNS の作成 → Custom domain → 証明書を待って HTTPS 必須 → 新しい住所の確認）
2. 新しい住所が 200 を返したら、PR #15（住所の書き換え）をマージし、Pages への反映を確かめる
3. 新しい住所で `BASE=https://umaredoshi.margheritaworks.com/ node scripts/e2e.mjs` を通す
4. 終わったら、トークンは消してよい（期限付きで作るのがよい）
