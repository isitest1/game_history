# 09 江戸の読み替え

## 決めたこと（2026-10-15）

- いちばん古い生まれ年を、1890年から **1800年（寛政12年）** まで広げる（ユーザーの依頼「今の仕組みで江戸も入れよう。高校とかはいい感じに読み替えて」）
- 3人の生まれ年は「どこも30年以上離す」だけを決まりにし、それ以外は決めない（docs/01 の「3つの生まれ年」）
- 仕組み（決断・人生の流れ・画面）は変えず、**江戸の人には、同じ決断をその時代の言葉と仕組みに読み替えて当てはめる**
- 境目の年は、学制（1872年公布）。それより前を「江戸の仕組み」として扱う（`isEdo(year)`：year < 1872）。お金は新貨条例（1871年）より前は「いまのお金で約○円」と書く
- 1890年より前の数字は推計（data/stats/edo.json、docs/03 の J 節）。トップページの下の「数字について」、母子手帳、出典、共有カードに断り書きを出す

## 生まれ年の出方（5,000回引いた結果）

| いちばん年上の人 | 割合 |
|---|---|
| 江戸（〜1867年） | 約41% |
| 明治・大正（1868〜1925年） | 約46% |
| 昭和（1926年〜） | 約14% |

真ん中の人が江戸に生まれるのは約3%。

## 読み替えの表

| いまの仕組み | 江戸（〜1871年） | 明治の初め（1872〜1889年） |
|---|---|---|
| 生まれた県 | 当時の国の名前（「信濃（いまの長野県）」）。県のおもな国で目安 | 県 |
| 家（親の仕事） | 百姓・武士・町人（商い・職人）・奉公人。武士は人口の数%、豊かな家ほど武士や大きな商家になりやすい | 農家・士族・商い・勤め |
| 小学校 | 寺子屋の手習い（通った割合は推計）。武士の子は素読 | 学制の小学校（授業料あり。就学率は文部省の統計） |
| 中学受験（12歳） | 武士の子は藩校。百姓・町人の子は郷学・私塾（少数） | 中学校 |
| 高校（15歳） | 藩校・私塾で学び続ける。女の子は裁縫・行儀の稽古 | 中学校・女学校 |
| 大学・短大（18歳） | 江戸・大坂・長崎の塾への遊学／医術などの専門の塾 | 東京大学（1877年）などの高等教育 |
| 就職 | 奉公（丁稚・女中、年季、口入れ屋）、家の田畑や商いを継ぐ。武士の長男は出仕、次男より下は養子か部屋住み | 商家や工場の勤め、役所 |
| 夢「大きな会社」 | 大店への奉公（番頭、暖簾分けをめざす） | 大きな商家や会社 |
| 夢「公務員」 | 武士になること（百姓・町人の子には身分の壁でまず叶わない） | 役人 |
| 夢「都会」 | 江戸（東日本）・大坂（西日本）へ出る。通行手形 | 東京・大阪 |
| 結婚 | 親や仲人が相手を決める結婚が9割（目安） | 同じ |
| 失業 | 奉公先から暇を出される／日雇い | 勤め先が傾く |
| 転職・独立 | 奉公先を替える、暖簾分け。武士は役目を替えられない | 店を移る、商いを始める |
| 家 | 町は長屋を借りる、村は代々の家。建てるときは大工に頼む | 同じ |
| お金 | 両替商、壺にしまう、堂島の米相場、お伊勢参り | 銀行（1873年〜）、株式取引所（1878年〜） |
| 病気 | 寝込んで医者にかかる。薬礼は自分持ち（1900年まで） | 1927年の健康保険法より前は全額自分持ち |
| 定年 | 家督や店を譲って隠居（60歳ごろ。1920年まで） | 同じ |
| 年金 | なし（1911年4月1日以前の生まれは、生きていれば70歳から老齢福祉年金） | 同じ |
| 介護 | 家で家族が看る | 同じ |
| 海外 | 渡航禁止（1866年まで） | 留学・移民など限られた人 |
| 車・自転車・電話 | ない（大八車、駕籠、手紙） | 人力車、汽車（1872年〜） |
| 学歴の表示 | 手習いを受けていない／寺子屋で読み書き／藩校・私塾で学んだ／専門の塾で学んだ／遊学して学問を修めた | 小学校まで／旧制中学卒／高等女学校卒／専門学校卒／旧制の高等教育を修了 |
| 死因 | 疱瘡・麻疹・はやり病・腹の病・労咳・お産・中風・老衰。飢饉や疫病の年は、その分だけ死因をそれにする | 同じ（死因の統計は1899年から） |

## 日々の場面

- 江戸の場面：data/daily/era_edo.json、明治の初め：era_kaika.json、明治・大正の年寄り：elder_meiji_taisho.json
- 時代を決めていない場面は昭和以降の暮らしを思い浮かべて書いたものが多いので、1890年より前の人には、近代の物の名前が入った場面を出さない（daily.ts の `OLD_BAN`）。それでも合わない場面には `notBefore`（その年より前には出さない）を付けた
- 親友・結婚記念日・子どもの入学・ペットなど、プログラムで作る場面も、年で書き分けた（消しゴム→栗、ランドセル→手習い、銀婚式は1930年から、など）

## 風景

- 1871年までは和紙色の空に、村は茅葺きの家と田んぼ、町は町家の並びとお城・火の見櫓（src/ui/scene.ts）。電柱は1880年から

## 未確認・今後

- 国と県の対応は「その県のおもな国」の目安（例：兵庫県＝播磨、福島県＝陸奥）
- 江戸の人口の地域差（東北の減少、西日本の増加など）は、県の重みに入れていない（北海道・東京・大阪・神奈川の重みを下げただけ）
- 苗字：江戸の百姓・町人の多くは公には苗字を名乗らなかった（1875年に苗字が義務になった）。ゲームでは3人に同じ苗字を付けたまま
