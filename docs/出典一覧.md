- 統計そのものの所在や、まだ使っていない統計の調査結果は [03_必要な統計データ.md](03_必要な統計データ.md) にある

## 0. 結論

1. **統計（`data/stats/`）は、すべて公的機関とリクルートワークス研究所が公開しているデータを加工して作った。** どれも「出典を書き、加工したことを書けば」再配布と商用利用ができる規約である
2. **再配布の可否が分からないデータの値は、リポジトリに入れていない。** 日本版死亡データベース（JMD）は照合にだけ使い、Human Mortality Database（HMD）とJILPTのExcel（無断転載禁止）は値の元にしていない
3. **出来事（`data/events/`）は862件で、89.6%（772件）に `verified: true` が付いている。** ただし、`pref.json` の160件は Wikipedia を出典にしており、一次資料での確認が今後の課題である
4. **決断の文章と生活の計算には、統計からの直接の値ではない「目安」が多い。** 預金金利、株の値動き、住宅価格の年収倍率、定年の年齢、寿退社の確率などである。画面やコードで「目安」と書き、下の4章に一覧を載せた

## 4. 決断の文章と生活の計算に書かれている固定の事実・目安

`src/sim/decisions.ts`（決断の文章）、`src/sim/engine.ts`（生活の計算）、`src/sim/stats.ts`（統計の読み込み）のコメントと文章から、統計ファイルを通さずにコードに直接書いた事実と目安を拾った。

「状態」の欄の意味は次のとおり。

| 状態 | 意味 |
|---|---|
| 出典あり | コードのコメントか、docs/03 に、確かめた出典がある |
| 目安 | コードに「目安」と書いてある。統計からの直接の値ではない |
| 未確認 | コードに「未確認」と書いてある |
| 出典の記載なし | コードにも docs にも出典が書かれていない。事実として広く知られているものも含むが、確かめ直しが要る |
