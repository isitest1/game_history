# 品質チェック

Awwwards の審査基準（デザイン40%、使いやすさ30%、独創性20%、内容10%）で、各10点満点で採点する。8点未満の項目があれば直して、もう一度スクリーンショットを撮る。

- 撮り方：`npm run build && npx vite preview --port 4173 &` のあと `node scripts/screenshots.mjs docs/screenshots`
- 画面：タイトル、母子手帳、人生、決断、決断の結果、最後の画面。スマホ（390×844）とPC（1440×900）、明るい表示と暗い表示
- 採点は自分で見て行う。数字は主観で、目安として記録する

| 独創性 | 7.5 | 構造は強い発明。ただし時代の描き分けが色違いにとどまり、活版・ブラウン管・プリクラらしさが弱い |

**指摘された問題（効果の大きい順）**
1. スマホの人生画面で本文が読めない
2. 最後の画面の棒グラフの数字が読めない
3. 時代の描き分けが色違い止まり
4. スマホの操作バーの選択肢が切れ、ボタンの意味が分かりにくい
5. 決断の「関係なし」に理由がない、最初からフォーカス枠が付いている
6. PCで小さすぎる文字と低いコントラスト
7. 単語の途中での改行、享年の行の高さのずれ、スマホの記録が縦に長すぎる
8. ガチャの演出が弱い、ステップの終わり／今の区別がない
9. 操作バーと列の位置のずれ、余白の不統一
10. 最後の画面の後半（叶わなかった望み、共有ボタン、もう一度）が尻すぼみ

**4周目に直したこと**
1. スマホの人生画面：3列には年・名前・状態・貯えだけを出し（ゲージは2×2に圧縮）、その下に「同い年の出来事」を年齢ごとに横幅いっぱいのカードで並べた。本文は15px
2. 最後の画面の棒：数字を棒の外（下）に14pxで出した。スマホの死亡記録は、行見出しつきの比較表にした
3. 時代の描き分け：1列目は二重罫・角ばった縁・明朝の見出し、2列目は湾曲した角・内側の影・濃い走査線・丸ゴシックの見出し、3列目は影なしのフラット。暗い表示の1列目の茶色いグラデーションをやめた
4. 操作バー：中身を列と同じ幅にそろえ、重点のチップの右端をぼかして続きがあると分かるようにした
5. 決断：関係のない人には理由（「中学を出てすでに働いているので、この決断はない」など）を出し、薄く表示。最初のフォーカスは見出しに置き、選択肢に枠が付かないようにした。PCでは選択肢の幅を640pxまでにし、16pxにした
6. 文字：補足の文字色を濃くし（--ink-3 を #5f5749 に）、ゲージや日付の文字を12px以上にした
7. 改行：全体に word-break: auto-phrase と line-break: strict をかけた。享年は1行にそろえた
8. ガチャ：上に寄せて空白を減らし、終わったステップに✓、今のステップを朱色にした。確率を大きくし「1000人のうち何人」も出す。最後の3つの生まれ年は裏返る動きで出す
9. 叶わなかった望みは3列にして、判子（否）を付けた。共有のボタンを1行に、「もう一度生まれる」を横幅いっぱいにした
10. 人生の記録は、選んだ人の時代の装いで出す
