# 品質チェック

Awwwards の審査基準（デザイン40%、使いやすさ30%、独創性20%、内容10%）で、各10点満点で採点する。8点未満の項目があれば直して、もう一度スクリーンショットを撮る。

- 撮り方：`npm run build && npx vite preview --port 4173 &` のあと `node scripts/screenshots.mjs docs/screenshots`
- 画面：タイトル、母子手帳、人生、決断、決断の結果、最後の画面。スマホ（390×844）とPC（1440×900）、明るい表示と暗い表示
- 採点は自分で見て行う。数字は主観で、目安として記録する

---

## 1周目（2026-10-14 夜）

| 基準 | 点 | 見たこと |
|---|---|---|
| デザイン | 7 | 3つの時代の書体と質感（明朝と紙／丸ゴシックと走査線／角ゴシックとフラット）は伝わる。人生の画面は、PCだと列の中が文字ばかりで単調。母子手帳はスマホで表の2列が崩れていた |
| 使いやすさ | 7 | 決断から結果までの流れは分かりやすい。スマホの3列は狭く、古い出来事は見出しだけになる。生存曲線のラベルが重なり、スマホでは文字が小さすぎる |
| 独創性 | 8 | 同じ選択の結果を3つ並べる見せ方と、時代ごとの描き分けは独自。時代の風景（家や町並み）がまだない |
| 内容 | 8 | 統計にもとづく数字が決断ごとに出る。出来事は862件 |

| 項目 | 結果 |
|---|---|
| Lighthouse（タイトル、モバイル） | 性能99、アクセシビリティ100、ベストプラクティス100、SEO100（直す前は性能85。出来事を後から読み込むようにして改善） |
| 横スクロール | なし（6画面×2サイズで scrollWidth を確認） |
| コンソールのエラー | なし |

**直したこと**
- スマホの母子手帳・死亡記録の表を、見出しと値の縦並びに変えた
- PCのタイトルの見出しが「生／まれる」で切れていたのを、改行の位置を固定して直した
- PCのタイトルの右側が空いていたので、3つの生まれ年の数字の札を置いた
- 明るさの切り替えボタンを、文字からアイコンに変えた
- ロゴのリンクの読み上げ名と表示の文字のずれ（Lighthouse の指摘）を直した

**次に直すこと**
- 人生の画面に、時代の風景（家・町並み）を入れる
- 生存曲線のラベルの重なりと、スマホでの文字の大きさ
- 人生地図のマスをスマホで大きくする

- 定年後も働く人の退職年齢を、70歳から65歳に直した
- 進学率が95%を超える年は、望めばほぼ高校に進めるようにした（定時制・通信制を含むため）
- 速さのボタンの読み上げ名と表示のずれを直した

**直したこと**

- 閉じられる重ねる画面には、上に固定の「×」ボタンを付けた
- 成否と文章のずれ（ポケベル、ゲーム、男性の育児休業）を直した

## 4周目（別のエージェントによる独立した講評）

自己採点が甘くならないよう、スクリーンショット26枚を別のエージェントに渡し、審査員の立場で採点してもらった。

| 基準 | 点 | 講評の要点 |
|---|---|---|
| デザイン | 6.5 | 明朝の見出しは品がある。ただしスマホの人生画面は1列約118pxで、本文が6〜7字ごとに折り返して読めない。PCは10〜11pxの文字が多い |
| 使いやすさ | 5.5 | 下のバーの選択肢が切れて見えない。決断画面で最初の選択肢にフォーカス枠が付き、選んであるように見える。グラフの数字が棒の上で読めない（コントラスト不足） |
| 独創性 | 7.5 | 構造は強い発明。ただし時代の描き分けが色違いにとどまり、活版・ブラウン管・プリクラらしさが弱い |
| 内容 | 8.0 | 出典つきの出来事と母子手帳は良い。「関係なし」の列に理由がない、叶わなかった望みが箇条書きだけ |

**指摘された問題（効果の大きい順）**
1. スマホの人生画面で本文が読めない
2. 最後の画面の棒グラフの数字が読めない
3. 時代の描き分けが色違い止まり
4. スマホの操作バーの選択肢が切れ、ボタンの意味が分かりにくい
5. 決断の「関係なし」に理由がない、最初からフォーカス枠が付いている
6. PCで小さすぎる文字と低いコントラスト
7. 単語の途中での改行、享年の行の高さのずれ、スマホの記録が縦に長すぎる
8. ガチャの演出が弱い、ステップの終わり／今の区別がない
9. 操作バーと列の位置のずれ、余白の不統一
10. 最後の画面の後半（叶わなかった望み、共有ボタン、もう一度）が尻すぼみ

**4周目に直したこと**
1. スマホの人生画面：3列には年・名前・状態・貯えだけを出し（ゲージは2×2に圧縮）、その下に「同い年の出来事」を年齢ごとに横幅いっぱいのカードで並べた。本文は15px
2. 最後の画面の棒：数字を棒の外（下）に14pxで出した。スマホの死亡記録は、行見出しつきの比較表にした
3. 時代の描き分け：1列目は二重罫・角ばった縁・明朝の見出し、2列目は湾曲した角・内側の影・濃い走査線・丸ゴシックの見出し、3列目は影なしのフラット。暗い表示の1列目の茶色いグラデーションをやめた
4. 操作バー：中身を列と同じ幅にそろえ、重点のチップの右端をぼかして続きがあると分かるようにした
5. 決断：関係のない人には理由（「中学を出てすでに働いているので、この決断はない」など）を出し、薄く表示。最初のフォーカスは見出しに置き、選択肢に枠が付かないようにした。PCでは選択肢の幅を640pxまでにし、16pxにした
6. 文字：補足の文字色を濃くし（--ink-3 を #5f5749 に）、ゲージや日付の文字を12px以上にした
7. 改行：全体に word-break: auto-phrase と line-break: strict をかけた。享年は1行にそろえた
8. ガチャ：上に寄せて空白を減らし、終わったステップに✓、今のステップを朱色にした。確率を大きくし「1000人のうち何人」も出す。最後の3つの生まれ年は裏返る動きで出す
9. 叶わなかった望みは3列にして、判子（否）を付けた。共有のボタンを1行に、「もう一度生まれる」を横幅いっぱいにした
10. 人生の記録は、選んだ人の時代の装いで出す

| 項目 | 結果 |
|---|---|
| Lighthouse（タイトル） | 性能98、アクセシビリティ100、ベストプラクティス100、SEO100 |
| Lighthouse（人生の画面、確認用の直接表示） | 性能86、アクセシビリティ100、ベストプラクティス100、SEO100。最大の描画が遅いのは、確認用の表示で出来事のデータを読み込んで30年分を計算してから描くため。実際の遊び方ではガチャのあいだに読み込みが済む |
| 通しで遊ぶテスト | エラー0、横スクロール0 |
